# Loop v2.1.0

Loop is lighter: it uses almost no energy when you're not using it, and
replies, typing, and switching chats are all smoother.

## Faster

- When nothing is happening, Loop uses almost no power, whether its window is
  open or hidden. Your battery lasts longer and your Mac stays cool.
- A reply coming in costs a fraction of what it did, and new text fades in
  smoothly.
- Typing, scrolling, and resizing the window stay smooth, even while a reply
  comes in.
- Loop opens faster, and long chats open almost instantly.

## Claude

- Claude no longer needs Node.js. If you installed Node only for Loop, you can
  remove it.
- Each Claude chat uses less memory.
- When you open a chat or start typing, Claude gets ready in the background,
  so replies start sooner.
- Chats you're not using are closed after a while, or when your Mac needs the
  memory, and pick up where they left off when you write again.

## Better

- Updates no longer ask before upgrading your data. A backup is still kept, and
  you can restore it in **Settings › Advanced**.
- Using Loop on one Mac from another is quicker: only what changed is sent.
- Loop is smaller to download.

## Fixed

- A step from a stopped reply no longer keeps spinning.
- Opening a chat with a table in a reply could make Loop quit. It doesn't now.
