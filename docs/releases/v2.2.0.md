# Loop v2.2.0

A calmer sidebar, one place to answer questions, and Loop tells you when work
is done.

- **Sidebar:** chats stay where you put them. Snooze a chat for later, or
  Settle it when you're done. Settle replaces Archive, and archived chats are
  now under Settled.
- **Questions and approvals** from Claude and Codex appear in one card you can
  answer from the keyboard.
- **Chats without a project**, for a quick question.
- **Background work stays visible** after a reply, and the chat is marked
  unread when it finishes.
- **See Claude and Codex thinking** while they work.
- **Worktrees:** a chat in a worktree has its own Git, Files, and terminal.
- **Git:** Commit & push and Create PR run in the background (⌘↩).
- **Workflows:** set up a project in a few clicks. New: Implement Spec and
  Retro.
- **Updates:** Loop installs its own updates when you quit, and can update
  Claude Code and Codex for you.
- **The Dock icon** shows how many chats need you.
- **Replies read better:** scroll up while one comes in, copy code in one
  click, and tables, lists, and images look right.

**Using Loop on two Macs?** Update both. Macs on different versions of Loop
can't open each other's projects.
