# Loop v2.3.2

Fixes from using 2.3.1 every day.

**Fixed**

- **Message box:** grows with long messages, keeps the line you're typing in
  view, and never runs over the branch and model row, even in a small window.
- **Opening chats:** a chat shows right away, complete, instead of blank or
  half drawn, and long chats open fast.
- **Side panel:** each chat keeps its own size. A new chat starts at the
  normal size instead of borrowing another chat's.
- **Pairing a Mac:** Show Pairing Code no longer hides Loop's window. An
  expired code offers a new one.

**Better**

- **Images** open in a clean viewer over a dimmed window: pinch or ⌘-scroll
  to zoom, double-click for full size, arrows to move between images, Esc to
  close.
- **Scroll bars** are thin and only show while you scroll, even with a mouse
  connected.
- **Command output** wraps long lines instead of scrolling sideways.
- **Running work** above the message box is one slim line per item.
