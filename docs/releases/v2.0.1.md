# Loop v2.0.1

Loop is faster, and a few things that didn't work in 2.0 now do.

## Faster

- Loop no longer keeps your Mac busy when you're not using it.
- New chats, typing, switching branches, and the sidebar are quick again, even
  with a lot of chat history.

## Fixed

- Chats from Codex and Claude show up in the right project, and keep the
  titles you gave them.
- Mark Unread and Generate title with AI work again.
- Archive, bring back, and delete chats in **Settings › Archive**, and delete
  projects.
- The Screen Recording **Open Settings** button opens the right place.
- If you updated from Loop 1, part of the old version could keep running in
  the background. Loop now stops it.
- Loop finds its workflows more reliably, and if it can't, it tells you how to
  fix it.

## Better

- Finished chats collect under **Completed** in each project.
- Type **/** anywhere in a message to find any Codex or Claude skill, and use
  more than one.
- Push and Pull work when GitHub has newer commits: yours go on top. If they
  clash, nothing is changed.
- Commit messages, pull requests, and chat titles are written by GPT-6 Luna in
  Fast mode.
- Tables in replies look like tables, and conversation text is a little
  smaller.
- Closing a terminal tab ends it, and closing the last one closes the panel.
