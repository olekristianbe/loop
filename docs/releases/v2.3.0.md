# Loop v2.3.0

A faster Loop, with a Browser and an iOS Simulator beside your chat.

- **Faster:** Loop no longer uses a full core while chats stream, keeps up
  with every reply, and writes far less to disk. The first launch tidies
  your data and makes it much smaller; a backup is kept as always.
- **Browser:** open your app beside the chat with **+** › Browser. Pick an
  element, mark a region, or draw on the page, add a note like "make this
  bigger", and it goes to the agent with a picture. Try phone, tablet, and
  laptop sizes. Your sign-ins are kept across projects.
- **Agents use the Browser:** they can open, read, click, type, and take
  screenshots in the same page you see. Type **@Browser** to make sure they
  use it.
- **iOS Simulator:** **+** › Simulator shows a device beside the chat. Tap,
  swipe, type, go Home, open the app switcher, or create a new device. Type
  **@Simulator** to have the agent drive it.
- **Plan usage:** a meter at the bottom of the sidebar shows how much of your
  Claude and Codex plans you've used and when they reset, with a warning
  before you run out.
- **Ship:** one click commits, pushes, opens a pull request, waits for its
  checks, merges it, and cleans up the branch and worktree. It asks first,
  and it merges without review, so use it with care. When any Git action
  fails, **Ask the agent to fix** writes the message for you.
- **Dictation:** press the microphone button, or hold Right ⌥, and speak.
  It runs on your Mac; the speech model downloads the first time.
- **Message box:** attach any file, like a CSV or a PDF. Lists continue as
  you type, start at any number, and pasted lists become real lists.
- **Replies:** finished work folds into one line, like "Worked 1m 3s", with
  edits and thinking still shown, and work in progress looks calmer. Select
  across a whole reply, tables no longer overlap the text, and links and file
  paths open with a click or a right-click.
- **Projects:** sort by what needs you, recent activity, name, or by hand.
  Hide a project, point it at a folder you renamed, merge two, or choose its
  icon, and more project icons are found.
- **Chats:** sending in a settled chat makes it active again, settling asks
  first when something is still running, and processes an agent left running
  show up so you can stop them.
- **Git changes:** image and other binary files show as Binary, with a
  before and after preview for images, and right-click to reveal any file in
  Finder.
- **Commits** made by Loop and its agents no longer add a Co-Authored-By
  line.
- **Updates** for Claude Code and Codex are noticed sooner.
- **Fixed:** notifications no longer arrive while a reply has only just
  started, and remote Macs work when Tailscale doesn't report a name.
- **Two Macs:** if you use Loop on two Macs, update both.
